# Human Reality Gate — 10 分目視試験プロトコル

自動テストは「壊れていない」ことしか証明しない。この製品の価値は **人が 10 分話して違和感が少ないか** で決まる。

## KPI（優先順）
1. **Listening 中の自然さ**（最重要。ユーザーが話している時間の方が長い）
2. 割り込み・発話開始の体感遅延
3. 口パクと音声の一致
4. 日本語の自然さ・返答の長さ
5. 「そこにいる感じ」(presence)

## 手順
- テスター 3〜5 人（社内外を混ぜる。音声 AI に慣れていない人を最低 1 人）。
- 各テスターにつき **Free Talk 5 分 + Interview 5 分**。同じキャラクター（Yui）、同じエンジン設定で。
- セッション画面のメニュー → **「評価パネル · Human gate」** を ON。気づいた瞬間にボタンを 1 タップ（時刻・Avatar 状態・直前の字幕が自動で記録される）。
- 終了後、Result 画面の 5 段階評価（Listening 自然さ / presence / 遅延 / 日本語の自然さ）を入力。
- 記録は broker `POST /api/feedback` → `docs/reports/human/<date>.jsonl`（strict_local 時はブラウザ内のみ。「JSON をコピー」で回収）。

## 観察項目（パネルのボタンと同じ）
| ボタン | 何を見るか |
|---|---|
| 口パクが変 | 音声と口の開閉がずれる / 無音で口が動く / 発話中に口が止まる |
| 頷きすぎ | 数秒おきに同じ頷き、内容と無関係な頷き |
| 視線が怖い | 固定凝視、白目寄り、不自然な逸らし |
| 瞬きが規則的 | 一定間隔の瞬き、瞬きゼロ |
| 身体が止まる | Listening 中に完全静止、呼吸が消える |
| 同じmotionが目につく | 直近数回で同じジェスチャー |
| 聞いている感じがない | 深刻な話に笑顔、達成の話に無反応 |
| 返答が長い | 3 文超、要約癖 |
| 相槌が多い | 毎ターン「なるほど」 |
| 割り込みが変 | 止まらない / 止まった後の復帰が変 |
| 発話開始が遅い | 沈黙が気になる（体感 1 秒超） |
| 👍良い瞬間 | 「人っぽい」と感じた瞬間（改善の基準点になる） |

## 判定
- PASS: 5 人中 4 人が Listening 自然さ ≥ 4/5、かつ「聞いている感じがない」「口パクが変」の記録が 10 分あたり 2 件以下。
- 記録は `docs/reports/human/` に残し、改善前後で比較する。
