# 利用評価のお願い

この資料は実施用です。評価済みの人数や結果を示すものではありません。

1. https://ai-meeting.web.app/ を開き、相手と用途、声を選んでください。
2. 1回目は雑談、2回目は英会話か面接、3回目は実際に役立てたい用途を選んで利用してください。途中で困ったことがあれば、そのまま記録してください。
3. 毎回の終了後に「自然に会話できた」「役に立った」「煩わしくなかった」を、1（そう思わない）〜5（そう思う）で回答してください。
4. 3回終えたら「また使いたい」「使えなくなると困る」を、それぞれ「はい／いいえ」で回答してください。

良い評価に合わせる必要はありません。未回答は空欄にしてください。氏名ではなく主催者から受け取った匿名IDを使ってください。

## 主催者向け

対象候補: `f54e8375153e6b4ba9676107b3526131a71a659da5cb0eab655295f95dfe40ea`

15人に各3回以上を依頼し、セッションID、開始終了日時、モード、使用機器、候補版、本人の回答を記録してください。回答は `../human-rating-template.json` の形式で非公開の保存先に回収します。テンプレートの `templateOnly` は実施・本人回答の確認後のみ false にします。回答・録音・個人情報を公開GitHubへpushしないでください。

各公開モードは有用性15標本以上が別途必要です。3用途だけの45セッションで全用途の評価が終わるわけではありません。

集計コマンド: `python3 ../latest-validation/aggregate-human.py <非公開の回答フォルダー> <対象候補>`

実Meet/Zoom試験: 各プラットフォーム30分10回・60分3回、実機2台以上。接続・音声・アバター・割り込み・再接続・入室拒否・待機室・参加者変更などの観測が必要です。試験後はYuiとTester双方の退出完了を確認します。
