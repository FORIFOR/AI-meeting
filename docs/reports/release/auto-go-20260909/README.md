# 自動検証と音声不具合の修正（2026-09-09）

Release = NO_GO。Botによる自動試験は15人×3セッションの実利用評価に換算していない。

## 修正・反映

- Geminiの発話上限8秒で、約9秒の依頼の末尾が失われる問題を修正。通常の無音検出は500msのまま、異常時の連続入力上限を120秒に変更。
- 名前の後の読点が欠落した「返してください」「確認してください」、および名前と読点の間に空白が入った呼びかけを認識するよう修正。他者についての発言を除外する動作は維持。
- 型検査、728テスト／72ファイル、公開用ビルド成功。音声・呼びかけ修正: `23d6f5f`。未使用agentの状態確認修正: `a147813`。
- 明示的なクラウド会話で不要なローカルagentの状態確認を抑止。自動選択・ローカル選択・ローカル機能の指定・strict_localでは必要な探索を維持。CORSを再現した同じlocalhost構成で2分再試験し、console/page/HTTPエラーはすべて0件（`health-smoke-assessment.json`）。速度基準や30分試験の合格を意味しない。
- Firebase Hosting `adb4c7bf4872053e`へ反映し、公開indexがビルド成果物と一致することを確認。詳細は`deployment.json`。

## 実行済みの観測

- 実クラウドGemini・5声で約9秒の合成音声を入力し、5/5で末尾の「確認してください」まで文字起こしされた。全5声で非有限値・クリッピングなし。各声1試行であり、人による音質評価ではない（`voice-output.json`、`voice-assessment.json`）。
- 実Meetで使った合成音声5種類をGeminiと修正後の呼びかけ判定器に通し、5/5で呼びかけと認識。各クリップは別セッションなので前の予定を参照する会話品質の試験ではない（`address-audio.json`）。
- 実Gemini TCP切断＋トークン取得への10秒間の通信障害／429／タイムアウト注入は各3/3で実セッションハンドルを使って復旧。物理デバイスやBluetoothの復旧試験ではない（各`*-series.json`）。
- 修正前の公開版でHosted MeetにYui／Testerが実入室し、約12分・30キューを実行。挨拶と予定確認の返答欠落を再現。Attendee状態取得APIのHTTP 502で停止したため30分完走には数えない。Yui／Testerとも`ended`確認済み（`meet-before-fix.json`）。
- 元の会議URLでの修正版Hosted Meet再試験は5分以内に入室承認がなく開始できず。両Botの`ended`を確認済み（`meet-after-fix.json`）。
- ローカル公開用ビルド＋実クラウドGeminiの30分連続会話試験は完走。207/209件の発話を認識、認識後の応答数は207件（件数と時刻の集計で、意味の正しさを評価した比率ではない）。応答遅延p50=1,484ms、p95=1,757ms、n=207でFAIL。画面／HTTPエラー0件だが、未使用agentへのCORSエラー366件があった（`soak-assessment.json`）。試験開始後の追加変更は会議の呼びかけ判定だけで、ロード済みのブラウザーの対象と最終配信版のハッシュ差は`source-provenance.json`に明記する。

## 残るリリース条件

- 応答遅延p50≦700ms、p95≦1500ms、その他音声・信頼性の必要サンプル。今回の5声では応答開始に約1.4〜1.5秒かかっており、速度基準を達成したとは言えない。
- 修正版の実Meet／Zoomの規定試験。各サービス30分×10回、60分×3回、実PC2台を満たす結果はない。Zoom参加URL未提供。
- 実際の15人による3セッションずつの利用・評価結果。合成音声やAIテスターでは代替しない。
- Hosted表示残高は試験前4.07、全Bot退出後3.43クレジット。両サービスの規定試験は2Bot構成で計約32Bot時間を要する。追加40クレジット／$20の購入承認を依頼中。自動購入はしていない。
- Gemini Developer APIの3.1モデルはモデル情報取得可能だが、実Live接続はプリペイド残高枯渇で拒否。現在のVertex経路は継続使用可能。高速化の代替モデルを使用可能とは記録しない。

`hosted-meet.mjs`は再実行用の合成音声テスター。会議URLは環境変数で指定し、認証情報・トークンを含むセッション記録はprivateな一時フォルダーに保存する。実行時間の満了だけを機能合格にせず、返答・無言・退出を別に確認する。
