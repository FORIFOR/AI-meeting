## 1. タスク追加の取りこぼし

ユーザー発話が継続している間にAI音声が重なると、小さい音の入力までエコー抑制が切り捨てていた。既に開いているユーザー入力は保持するよう修正。エコーの戻りを抑える既存テストも維持。

文字起こしが誤る場合の確認UI、割り込み後のツール要求の世代管理と併せて、3発話の実Vertex・合成マイク・実ブラウザ試験で、牛乳の完了、金額確認の追加、見積書の15時期限、残件の音声返答を確認（tasks/tasks.json）。誤認識一般の解消や、全ての表現での再現率保証ではない。

18分試験は、brokerが後続版00007へ上書きされて情報取得APIを失っていた環境で実施。測定後にAPIを00008で復元しHTTP200とCORSを確認。ただしニュース配信元が503を返すことがあり、取得成功を装わない。18分の数値をAPI復元後の全システム認証には流用しない。環境はdeployment.jsonに記録。

音声の聞き取りやすさ・実機の雑音下精度・人の満足度などは未評価。全音声品質をPASSとはしない。

## 3. 実Meet / Zoom・人による評価

両プラットフォームの起動前チェックを実行したが、MEET_URL / ZOOM_URLがなく開始不可。GitHubにある自動テスターの限定Meet GO記録は確認済み。必要回数や実参加者15人×3セッションの結果とは異なる。

required-inputs.mdに会議URL・入室承認・実機・参加者の必要情報を整理。aggregate-human.pyは実際の個票の候補版・日時・重複・評価範囲を検証する。空票と架空回答で人数を埋めない。
