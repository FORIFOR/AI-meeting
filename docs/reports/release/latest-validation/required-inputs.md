# 実会議・利用評価の実施に必要なもの

Meet/Zoomの事前チェックを実行し、両方ともテスト専用URLが未設定で開始不可。クラウドにはAttendee API設定があるが、任意の既存会議に参加しない。

- テスト専用Meet URLとZoom URL。参加許可・待機室を承認できる担当者と実施時間。
- 2台以上の実機。各公開対象プラットフォームで30分×10回、60分×3回。役割交代・割り込み・通信切断・復帰・機器変更などを記録する。
- 15人以上が各3回以上利用し、本人が自然さ・有用性・煩わしくなさを1〜5で回答。3回終了後、再利用意向・なくなると困るかをYes/Noで回答。

評価票は ../human-rating-template.json、手順は ../human-study.md。実参加者ID・実セッションID・候補版・日時・回答を記録し、個票は非公開フォルダへ保存する。

集計コマンド: `python3 aggregate-human.py 個票フォルダ 候補buildId`
空票・別候補・重複セッション・範囲外評価を拒否する。人数・回答不足はBLOCKED。空フォルダ試験は集計器の検証であり、実際の参加者調査ではない。

GitHub追加記録 vertex-one-to-one-20260909.json は自動テスターによる限定Meet試験。15人評価・必要回数・人の音響品質の証拠に置き換えない。
