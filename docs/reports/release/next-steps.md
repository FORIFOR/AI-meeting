## 残件対応の再検証

- 1対1ハーネスの割り込み計測が音声合成時間を含んでいたため、全音声を接続前に生成するよう修正。再測定は65ms、停止後の入力中にプロバイダから出た音声0フレーム。以前の1031msを製品の停止遅延として扱わない。これは物理スピーカーの音響試験ではない。
- ハーネスは「応答が出た」だけで内容の期待条件をPASSにしていたため、内容未判定はREVIEWに変更。JSON証拠も保存する。ニュース・日付・断片への返答は原文を評価する必要がある。
- Geminiの無音待ちを500msから350msに変更した比較段階では、280msの息継ぎを保持する回帰試験を追加（Geminiテスト29件PASS）。最終250ms設定と実測は冒頭を参照。
- Downloads / Documentsに署名用.p12 / .pfx / .cerは見つからず、DockerにAttendeeコンテナ・イメージはなく、Attendee用SSHエイリアスも未設定。元環境の接続先または証明書の復元が必要。
