# Presence incidents

One folder per `sessionId`, one `<id>.json` per 「不自然だった瞬間」 tap (±5 s of events / avatar state / motion / emotion / gaze / VAD / latency / errors).
`<id>.mic.wav`, `<id>.assistant.wav`, `<id>.jpg` exist **only** when the tester opted in during that session (default OFF). Everything except this README is git-ignored.
