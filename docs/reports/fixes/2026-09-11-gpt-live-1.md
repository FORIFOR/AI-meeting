# GPT-Live 1 integration

One-to-one Settings > OpenAI > GPT-Live 1 opts into a separate Live WebRTC adapter. Realtime and Gemini defaults remain unchanged; meeting Bots keep their existing provider route. The server exchanges SDP through /v1/live/sessions; browser never receives the project key. Marin is the Live default voice; existing Realtime voice IDs are not forwarded. Live itself has no image-input support and custom task functions are not registered in this initial adapter. Responses delegation uses gpt-5.6-terra, 512 maximum output tokens, no external action tools. Session recording disabled.

Microphone is attached before negotiation. Audio output travels through existing SpeakerOutput and avatar audio tap; local energy detection drives speaking state independently of transcript timing. Full-duplex local VAD does not cancel on every acknowledgment; explicit tap still stops local playback and requests silence. Input transcript deltas are retained as fragments, not treated as authoritative turn-completed events. Live final duration is cumulative, kept on the result, and missing close confirmation stays unconfirmed. Backend usage is separate from voice duration; no unverified price conversion added.

Validated with official documentation, read-only /v1/models/gpt-live-1 access check, typecheck, build and mocked tests. No paid Live session was created, so actual speech quality, voice latency, backend delegation and live account billing remain unverified.
