# Thinking Meeting — Phase 1

Latest product direction supersedes the URL-first home: the first encounter is a one-to-one thinking conversation. Home now offers character preview + direct Talk, keeps the meeting invitation below, and folds specialist modes into an optional disclosure. Credits stay visible.

A thinking_ja persona guides one-question-at-a-time conversation, distinguishing user decisions from suggestions and reflecting open questions/next steps. Home Talk starts this persona directly through the existing Session route. The recent-session shortcut is renamed to avoid claiming cross-session memory it does not establish.

Validation: web typecheck, persona tests (5), Home routing test (1), production build. Local headless browser: 1280px and 390px visual checks, no horizontal overflow. External requests blocked; no paid AI/meeting session started.

Future phases from the supplied product vision remain separate work: scoped person/project/meeting memory with user review/deletion; memory-grounded multi-party intervention; specialist teams; external action drafting/execution and permission boundaries. No connector access, third-party messages, subscriptions, calendar events or pricing plans were created by this change.
