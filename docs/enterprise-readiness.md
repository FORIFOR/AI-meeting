## 提供段階

| 段階 | 現在の扱い | 次の条件 |
| --- | --- | --- |
| L1：企業への紹介 | 機能デモと技術説明は可能。L1の全条件を満たしたという認定はしていません。 | 音声を含む同一デモ10回の再現、実人間100会話の計測と内容評価。 |
| L2：有償PoC | 要件整理・個別開発の相談を受付。顧客データを扱う標準PoCの受入準備完了は未宣言。 | 顧客ごとの分離・アクセス権・保存/削除・録音同意・予算・合否基準を決定し、実装と検証。 |
| L3：本番導入 | 未到達。 | SSO/RBAC、監査、運用監視、障害対応、SLA、保持方針、会議連携ごとの実通話検証。 |

相談の送信で契約や料金は発生しません。受託開発・現場への実装支援は、対象業務と完了条件を合意してから範囲・納期・費用を決めます。将来の機能や達成率の推測を、現在の実績として販売しません。

## 失敗する場合を見せる

機密情報のないデモ用タスクで実施します。

1. **不正なバックアップ**：タスクを1件保存し、`{"version":999,"tasks":[]}` をファイルとして復元画面で選ぶ。エラーが出て、既存のタスクが残り、復元成功とは表示されない。
2. **保存容量不足の模擬**：反復用ブラウザー検証はIndexedDBへの書込みを意図的に失敗させる。追加成功を表示せず、再読み込み後にも未保存のタスクを表示しない。実際にディスクを満杯にする試験ではない。
3. **聞き取りが不確か**：変更元の発話と一致しないタスク変更は、確認待ちかエラーになる。確認待ちの提案は保存しない。[永続化テスト](../apps/web/src/state/taskWorkspace.test.ts)。
4. **認証・利用枠・接続終了**：無認証・未確認アカウント・回数超過・使用済みチケットを拒否。致命的な接続エラーではマイクと再生を終了する。[接続ライフサイクル試験](../apps/web/src/session/SessionController.lifecycle.test.ts)。

Gemini/OpenAIの実サービス障害、実機のBluetooth切断、マイク差替え、Safari/Firefox、バックグラウンドからの復帰は、この一覧で検証済みとはしていません。

## データの行き先

| 操作 | 送信・保存先 | 現在の制約 |
| --- | --- | --- |
| 入力だけでタスクを整理 | ブラウザーのIndexedDB | 端末・アカウント間の同期なし。同じブラウザープロファイルを他人と共有しない。削除操作・JSONバックアップを提供。 |
| 公開版の音声会話 | ブラウザー → Google Cloudの中継 → Vertex AI（現在us-central1） | 音声・発話・会話に利用するタスクを送信。日本国内だけで処理する構成ではない。 |
| メールログイン | Firebase Authentication | メール確認済みを要求。IDトークンは設定済み中継先だけへ送信。 |
| 利用枠 | Firestoreにハッシュ化ユーザーID等の予約記録 | アカウント削除でも過去の利用予約は返却しない。 |
| 計測JSONの保存 | 利用者が明示操作でダウンロード | 数値・セッションIDのみ。音声・字幕本文・タスク・メールは含めない。自動テレメトリーには生のタイミング配列を追加送信しない。 |
| 目視評価・不具合記録 | 選んだプライバシー設定と記録方法による | 字幕等を含む場合がある。計測JSONとは別物。共有前に内容と同意を確認。 |
| 導入相談 | Google Cloudの非公開Firestore | 90日後に削除対象。広告計測や音声AIの入力にしない。 |

会話履歴を企業別に永続保存する機能、企業向けの録音管理・PII自動除去・監査ログは未整備です。クラウド事業者側の保持条件は契約確認が必要です。[ホスト版の仕様](hosted-access.md) · [相談データの運用](site-intake.md)。

## 費用の前提

公開体験は利用者への自動課金なし。1回180秒・1ユーザーUTC日あたり1予約・全ユーザー合計UTC月30予約です。失敗・内部検証も枠を消費します。これはクラウド全体の円建て請求上限ではありません。

セルフホストの**費用計画の例**：現在の接続モデル `gemini-live-2.5-flash-native-audio` に対応するGoogleのGemini 2.5 Flash Live APIの公開単価は、100万トークン当たり入力音声$3、出力音声$12、入力テキスト$0.50、出力テキスト$2です。[公式料金表（2026-09-13確認）](https://cloud.google.com/vertex-ai/generative-ai/pricing)。

| 計画上の単位 | 仮定 | モデル料金の概算（USD） |
| --- | --- | ---: |
| 3分の1セッション | 請求対象の合計が入力音声15,000・出力音声10,000・入力テキスト10,000・出力テキスト1,000トークンの場合 | $0.172 |
| 合計1時間 | 上記3分セッションを独立して20回 | $3.44 |
| 1ユーザー/月 | 上記セッションを月20回 | $3.44 |

これは**実測請求額・料金プラン・上限額ではありません**。音声の長さから上記トークン数を実証したものではなく、予算計画用の明示的な仮定です。式は `(入力音声×3 + 出力音声×12 + 入力テキスト×0.5 + 出力テキスト×2) / 1,000,000`。

Live APIはターンごとに過去のコンテキストも入力課金されます。上記の入力仮定はその再処理を含む請求対象総量であり、連続60分は独立3分×20回と同額とは限りません。クラウド中継、DB、通信、認証、会議ボット、運用人件費、税、為替は含みません。顧客PoCでは実際の利用量と請求を照合して更新します。

## 次の判断点

新機能を広げる前に、[実会話ベンチマーク手順](conversation-benchmark.md)に従って成功・失敗の全試行を残します。実人間100〜300会話と15/30/60分の実環境検証は、参加者の同意と別途管理された実施環境が必要です。自動化できるのは収集後の検証・集計であり、人間による利用実績そのものは生成できません。
