# VRM起動・配布の分離

本番のYuiは維持する。外部アバターAPIを必要としない起動経路には、既存のthree-vrmと追加したwLipSyncを使う。Anamは通常版の任意連携として残し、初期状態では利用しない。

## APIキーなしで試す

```sh
pnpm install
pnpm dev:oss
# http://localhost:5173/vrm-demo.html
```

テスト音・手元の音声ファイルを既存SpeakerOutputで1回だけ再生し、そのtapから口パクを動かす。VRMファイル・音声ファイルの選択はブラウザー内で完結し、外部へアップロードしない。無音時の閉口、割り込み、聞く/考える動作を確認できる。実AIの会話ではないので、AIとの会話には別途ローカル音声AIまたは通常版のクラウド設定が必要。

同梱モデルは公式の `VRM1_Constraint_Twist_Sample`（pixiv Inc.）で、アプリ独自の看板キャラクターではない。指定のAvatarSample_A公式配布がVRM 0.0のため、最初のVRM 1.0確認にはこのモデルを採用した。AvatarSample_Aを含むVRM 0.0/1.0のローカル持ち込みには対応するが、個別モデルの利用条件・互換性は別に確認する。

モデルは[VRM Public License 1.0](https://vrm.dev/licenses/1.0/)とファイル内の許諾設定に従う。全素材へコードのライセンスを適用しない。出典・ハッシュは `characters/vrm-sample/SOURCE.json`、条件は同じディレクトリの `LICENSE.md` に記録する。

## OSS用ビルド

```sh
pnpm build:oss
# apps/web/dist-oss が配布用出力
```

通常版の `apps/web/public` はコピーしない。`scripts/prepare-oss.mjs` が公式VRMサンプルとアイコンだけを専用ディレクトリへ準備する。Live2D Core、Yui等のLive2Dモデル・派生画像/動画、運用クレジットデータは対象外。Anam/Live2D/HeyGen/Tavusのアダプターはビルド時に除外し、通常版の実装コードは保持する。Google Fontsへの自動接続は通常版を含めて除外し、OS標準フォントへフォールバックする。

OSS初期設定は `strict_local` / `local` / `offline` / `vrm-sample`。保存キー `rcai.settings.oss.v1` は通常版 `rcai.settings.v1` と分離する。アバターだけでなく音声AI・解析・テレメトリー・会議Botのクラウド経路を既存のstrict_local境界で止める。外部連携を利用するには通常版で各サービスと素材の条件を確認して設定する。

## 音声同期と失敗時

WASM初期化や解析を音声再生より前に待たない。初期化・失敗時には既存Analyzerへ戻る。Workerの解析待ちは制限し、古い解析結果と割り込み前の結果は破棄する。5口形の推定精度はキャラクターや声に依存し、日本語の自然さの保証とは分ける。

VRMファイルの読込失敗・WebGL非対応は既存canvasの簡易表示へ戻り、その旨を表示する。元モデルの外見を再現した表示とは扱わず、キャラクターの名前・音声・会話の役割は維持する。有料APIには自動接続しない。診断には要求した方式と実際の方式を別々に記録する。

## Anamは任意

通常版では、運用者のキーとキャラクター対応表を設定した上で、利用者が自然表示を選ぶ場合だけ接続する。選択は保存され、AnamへAIの返答音声を送ること、返答に会議内容が含まれる場合があることを画面で説明する。ユーザーの生のマイク音声をAnamへ送る経路は追加しない。

Live2Dサンプルの画像をAnamへ登録することは、今回の実装・素材監査で許可した操作ではない。用途の権利を確保したモデル・画像とサービスの契約条件を確認する。比較評価や契約の問い合わせは今回自動実施しない。

## GitHub公開と商用運営

アプリ固有コードはApache-2.0、対象外の素材・上流コードは[NOTICE](../NOTICE)に記載する。初期デモは外部アバターAPIを必要としない。Anam、Live2D、Attendee等の素材条件・サービス契約は、それぞれの利用者が用途に合わせて確認する。公開ホストはAPI不要のデモに限定し、音声AIとの実会話はセルフホスト側で各自のproviderを設定する。
